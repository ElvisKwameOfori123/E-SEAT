# Outputs

This directory will contain the frozen replication outputs produced by the E-SEAT master pipeline and the publication cartography script.

Planned subdirectories:

- `tables/` for manuscript and appendix tables;
- `figures/` for Stata-generated analytical figures;
- `maps/` for publication-quality maps;
- `county_outputs/` for frozen county-level analytical files used in mapping and replication.

Generated outputs will be added only after the revised manuscript and final analytical run are frozen so the repository matches the reported results exactly.
